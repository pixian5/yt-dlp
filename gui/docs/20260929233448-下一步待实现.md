## 建议：把 GUI 迁成独立外挂项目

建议新建 `pixian5/yt-dlp-gui`，并从 `gui/` 子树保留历史拆出。拆分过程需先确认目标仓库及远端，再用 Git 子树拆分或等效的历史保留方案；拆分验证完成后，核心仓库恢复为纯上游树，避免在上游仓库根目录维护 GUI 文件。不要把 GUI 改成对 `yt_dlp` 内部模块的猴子补丁。

## 解耦方案

1. GUI 项目独立维护 `VERSION`、依赖、文档、测试和发布节奏。
2. 将 yt-dlp 调用收口到单一适配层：优先支持显式 `YT_DLP_EXECUTABLE`/命令配置；保留 `YT_DLP_CORE_DIR` 作为源码检出开发模式；不要从 GUI 导入核心私有 Python 模块。
3. 适配层统一负责命令构造、环境变量、版本探测和能力检查；GUI 只消费稳定 CLI 参数，并对不兼容版本给出清晰提示。
4. CI 对最低支持版与最新上游版运行命令组装、解析/格式选项及 GUI 单测；升级核心只更新兼容矩阵并执行集成测试，不重放核心补丁。
5. 独立发布 GUI；文档说明如何安装 yt-dlp 核心以及如何通过设置指向另一份核心。
