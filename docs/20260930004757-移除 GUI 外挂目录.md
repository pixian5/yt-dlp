# 移除 GUI 外挂目录，改为同级独立项目

操作时间：2026-09-30 00:47（Asia/Singapore）

## 背景

本仓库在 `gui/` 子树内维护 yt-dlp 的 Tk 图形界面外挂。GUI 与核心代码已经隔离（不导入 `yt_dlp` 私有模块，只用子进程调用 `python -m yt_dlp`），但共用一个仓库会带来两个问题：

1. 上下游更新后，核心仓库的官方检查（`ruff check .`、`make offlinetest`）会扫到 GUI 文件，GUI 的 lint 诊断会阻塞核心的检查流程。
2. GUI 的版本、依赖、发布节奏与核心混在一起，任何一侧的调整都要改同一个仓库。

## 本次操作

1. 备份：`/Users/x/code/yt-dlp-gui-pre-split-20260929234547.tar.gz`（拆分前 `gui/` 的完整压缩包）。
2. 拆出：`git subtree split --prefix=gui --branch=codex/gui-project-extract`，克隆为同级仓库 `/Users/x/code/yt-dlp-gui`，分支改名为 `main`，保留原提交历史。
3. 新工程补齐：`pyproject.toml`、`LICENSE`、独立 `.venv`、`tests/test_core.py`（核心路径定位）、中文提示、独立 Ruff / autopep8 规则、版本 `0.0.9` → `0.1.0`。
4. 新工程验证：12 项测试通过；`ruff check .` 与 `autopep8 --diff` 无问题；`./run_gui.sh` 启动冒烟成功（日志确认 `Core: /Users/x/code/yt-dlp`）并按 PID 正常停止。
5. 删除本仓库的 `gui/` 子树（含运行期残留 `run_gui.log`、`run_gui.pid`），本仓库恢复为纯上游布局。

## 之后的使用方式

```bash
# 核心仓库：只跟踪上游
cd /Users/x/code/yt-dlp
git fetch upstream && git merge upstream/master

# GUI 项目：独立开发，默认从同级目录定位核心
cd /Users/x/code/yt-dlp-gui
./run_gui.sh
# 或指定其它核心检出
YT_DLP_CORE_DIR=/absolute/path/to/yt-dlp ./run_gui.sh
```

核心版本继续跟随上游 `yt_dlp/version.py`，不因为仓库结构调整而改动，避免与上游合并产生无意义冲突。
